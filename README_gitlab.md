**Zig / C**（GC レスな物理メモリ制御、`comptime` 検証、`libxev` / `io_uring` 非同期 I/O）によるシステムプログラミングおよび **Linux / Arch Linux**・**ISO/IEC 7816 APDU** 基盤構築を専門としています。また、ゼロ知識証明（ZKP）と自己情報主権（SSI）に基づくプライバシー保護デジタルアイデンティティ研究機構 **[ZK-Sovereignty Japan](https://gitlab.com/zk-sovereignty-japan)** を主宰しています。

- **Systems & Networking:** Building low-latency networking components, DNS/load-balancing tools, and **OHTTP (RFC 9458)**-aligned relays in **Zig** (`libxev` / `io_uring`).
- **Ecosystem & Security:** Refining Arch Linux tooling, smartcard / APDU workflows, **Reproducible Builds**, `mlock`/zeroize key protection, and PQC-ready manifests.
- **Privacy R&D:** Advancing Zero-Data-Retention digital identity, local IC-chip ZKP generation, and cryptographic unlinkability initiatives at **[ZK-Sovereignty Japan](https://gitlab.com/zk-sovereignty-japan)**.
